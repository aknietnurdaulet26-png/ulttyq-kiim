# SVG иллюстрациялар

Барлық суреттер осы жоба үшін векторлық пішіндерден жасалған. Үшінші тараптың суреттері немесе эмодзи қолданылған жоқ.

Бұл — сабаққа арналған стильдендірілген көрнекілік. Нақты тарихи өңірлік костюмнің музейлік реконструкциясы емес. Сәукеле — қалыңдықтың салтанатты бас киімі; күнделікті бас киім ретінде түсіндірілмеуі керек.

## Қабаттарды орналастыру
- `male.svg`, `female.svg` және киім қабаттары: `viewBox="0 0 300 480"`.
- Бас киімі: шамамен y=0–90; бет y=65–130.
- Иық y=140, бел y=240, аяқ y=420, аяқ киім y=400–450.
- Қабат реті: кейіпкер → шалбар/көйлек → мәсі → камзол/шапан/ішік → белдік → бас киімі.
- `thumb-*.svg` файлдары сол түпнұсқа векторларды қиылған viewBox арқылы үлкенірек көрсетеді.
- `hero.svg` — толық дербес мұқаба иллюстрациясы; `ornament.svg` — қошқармүйіз негізіндегі қайталанатын өрнек.
